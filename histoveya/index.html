A reference atlas for South Asian cancer histopathology.

An open-access digital pathology atlas of whole-slide cancer images and clinical metadata from South Asia, built to close the gap in global reference imaging. It exists so the diagnostic models the region's pathology services depend on can be trained and tested on tissue from the patients they will be used on.

Identity
Slide ID, case ID, sibling slides from the same case
Diagnosis
Text diagnosis, ICD-O-3 morphology code, grade, stage
Case
Primary site, sex, age, reporting laboratory, consent status
Acquisition
Scanner, magnification, microns per pixel, pixel dimensions, file size
Quality
QC outcome, release date, whether an attention map is published

Getting the images

Filter to the cohort you want, export the manifest as CSV, then pull the slides with the command line client. The manifest is the unit of reproducibility. Keep it with your results and anyone can rebuild the same set.

pip install histoveya histoveya get --manifest manifest.csv --out ./slides

Images and metadata are released under CC BY 4.0. Clinical free-text fields are withheld. Re-identification attempts are prohibited under the terms of use.

02

Why South Asia needs its own reference atlas

Close to a quarter of the world lives here. Under one percent of the imaging behind public pathology datasets comes from here.

South Asia is close to a quarter of the world's population and under one percent of the imaging data behind public pathology datasets and the diagnostic models built on them. The models are still used on patients here.

The gap shows up as weaker accuracy for exactly the patients those models are meant to serve. Staining conventions, case mix and tissue handling all differ from what the models were trained on, so a model that reads a slide well in one country can read the same tumour poorly in another. A reference set from the region is what lets anyone measure that difference instead of assuming it away.

Slides are de-identified at source under institutional ethics approval. Nothing here is cleared for clinical or diagnostic use.

Write to us with your scanner, your usual stains and roughly how many cases you hold, and we will send the transfer and consent paperwork.

Home › AI analysis

AI analysis

Run a trained model over a reference case and read what it returns.

In development

The module is not built yet.

When it is, you will pick a reference case from the atlas, run a model over it, and get back three things: a classification, an estimate of how confident the model is in it, and a suggested IHC panel to follow up with. The attention map behind the classification will open in the viewer alongside it, so the output can be checked against the slide rather than taken on trust.

What it will return

Classification
The model's call, with the label set it was trained on
Confidence
How sure the model is, and on what basis
Suggested panel
IHC stains that would confirm or rule out the call

There is deliberately no sample output on this page. A fabricated classification or a made-up confidence figure would be taken for a real one, and this is the part of the site where that would matter most.
